# A&M Site Backend

This is the backend API for the A&M website.

Built with:
- Node.js
- Express
- PostgreSQL
- Deployed on Render

---

## 🚀 Live API

https://a_minfinity_database.onrender.com

---

## 📦 Installation (Local Setup)

1. Clone the repository

git clone https://github.com/movffasea-byte/GYANG/index.html

2. Install dependencies

npm install

3. Create a .env file

DATABASE_URL=your_postgresql_connection_string
JWT_SECRET=your_secret_key

4. Start the server

npm start

---

## 📂 API Endpoints

GET /products  
POST /login  
POST /register
